# Home Assistant

Seven nodes that make a ThingStudio board a Home Assistant device over MQTT discovery: put an `ha device` and a few
entity nodes in a flow, deploy, and the board shows up in Home Assistant with its sensors, switches and controls. The
larger example: a shared library, generated compile hooks and an external contract.

**Status:** work in progress: compile-, vector- and MQTT-tested; the hardware pass is partly done (kitchen-sink C3)
· **ThingStudio:** App v0.14.0 or later · **Nodes:** `ha device`, `ha sensor`,
`ha binary sensor`, `ha switch`, `ha number`, `ha select`, `ha button`

`tools/` holds that and the probe and clean-up tools for a real Home Assistant. `docs/working-notes/` holds the set's
scoping, plan and briefings: history, not documentation.
